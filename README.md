# customer_shopping_behaviour_anlytics
This is a data analytics project that integrates Python for data cleaning, SQL for schema design and business queries, and Power BI for interactive dashboards - all focused on uncovering insights from customer shopping behaviour.

# Customer Shopping Behavior Analysis

## Overview
This repository contains an end‑to‑end workflow for analyzing customer shopping behavior.  
It integrates three components:
- **Python data cleaning** to preprocess raw records
- **SQL schema and queries** to structure data and extract insights
- **Power BI dashboard** for interactive visualization

The objective is to transform raw purchase data into actionable insights for marketing, inventory planning, and customer segmentation.

---

## Workflow
- **Data Cleaning (Python)**  
  Missing values handled, datatypes standardized, duplicates removed, and a cleaned CSV exported.

- **Database Schema (SQL)**  
  Relational table `customer_shopping_behavior` designed with appropriate datatypes for demographics, purchases, discounts, and ratings.

- **Business Insights (SQL Queries)**  
  Queries developed to address practical business questions, including:  
  - Revenue by category  
  - Discount effectiveness  
  - Revenue by gender  
  - Customer segmentation  
  - Age group contribution  
  - Subscription impact  
  - Top products by rating  

- **Power BI Dashboard**  
  Visuals created to highlight revenue trends, demographic contributions, discount usage, and product performance.

## Key Insights
- Fashion and electronics categories generate the highest revenue.  
- Discounts do not consistently increase purchase amounts, requiring optimization.  
- Subscribed customers show higher average spending.  
- Loyal customers (previous purchases >15) form a strong revenue base.  
- The 26–35 age group contributes the largest share of revenue.
